# Testfälle für den Skill

Drei Prüf-Prompts, die eine Lehrkraft so eingeben würde. Sie laufen gegen die echte scobees-Instanz (Testbereich benutzen!) und werden deshalb von Hand in Claude Desktop ausgeführt: Prompt einfügen, Ergebnis gegen `case.yaml` (`expected_outcome`) prüfen, Befund in `docs/skill-notizen.md` festhalten. Wer Claude Code hat, kann sie auch mit `claude plugin eval skills/scobees-lernpfad` laufen lassen (echte, abgerechnete Läufe).
